# DyGKT-ContextAware

A context-aware extension of **Dynamic Graph-based Knowledge Tracing (DyGKT)**, developed during a research internship at KTH Royal Institute of Technology.

The project introduces a contextual neighbor sampling strategy combining temporal recency and skill relevance to improve knowledge tracing predictions.

For more details on the methodology, implementation, and experimental results, see the **project report linked in the repository's About section**.
